# InvestLens · 盈利质量研究台

把投资命题拆成待核验问题，读取公开年报，计算正反证据，人工复核后保存研究工作稿。三个独立入口使用同一个证据内核，各有完整产品流程。

| 题目 | 产品 | 主要能力 |
| --- | --- | --- |
| 第1题 AI Native | 盈利质量初筛 | 免费模型语义拆解、规则对照、原文定位、人工复核、指标与工作稿 |
| 第2题 多证据验证 | 命题验证室 | 澄清与修订、支持/反对/未知、冲突隔离、原始值、比较与追问 |
| 第3题 投资 X Buddy | 个人Agent工作台 | 工具注册、动态计划、审批、预算、上下文压缩、记忆、持久检查点与恢复 |

## 无密钥、无付费API的启动方式

需要Node.js 22+；使用包内下载助手还需要Python 3标准库。普通运行无需安装npm依赖，SDK已随源码提供。

```bash
node preview.mjs
# 浏览器打开 http://127.0.0.1:8002/?view=native
# 第2题 ?view=verify；第3题 ?view=buddy
node --test test.mjs
node build.mjs
node validate-artifact.mjs
```

在支持WebGPU及shader-f16的Chrome/Edge中点击“启用免费AI”，等待加载，然后建立计划。模型建议出现后会停在人工审核：取消无关项、补充漏项、修订方向与标准，再确认执行。首次下载约320MB权重，后续同源缓存可复用。Qwen3-0.6B在浏览器内推理，研究输入不提交远程模型服务器，没有按次API费用；设备、网络、电费未估算。

公网入口也可启用本地模型。若浏览器直连官方模型仓库超时，可先运行上述预览，在公网页面选择“本机下载助手”。助手只监听127.0.0.1:8002，固定允许官方公开模型资源，不接收研究目标，不代理任意URL。浏览器若询问访问本机网络，需由设备使用者允许。本机、GitHub Pages各自维护缓存，首次分别下载到浏览器；助手的已校验磁盘文件可复用。清理浏览器网站数据会移除缓存与研究资料。

不支持GPU或下载失败时，页面明确提示“模型未启动”，可继续规则核验。Safari规则路径已实际验证；免费GPU模型本次在Chrome实测，不声称所有浏览器都能运行。

## 实际验证与AI角色

真实运行时模型输出、tokens和时延见 AI_EVALUATION.md 与 AI_USAGE_VALIDATION.md。6个第二组预设命题中，模型覆盖9/9相关指标，提出21项，指标选择准确率42.9%；两条下降方向误判。模型提出问题的覆盖较关键词规则高，但不能无人审核。标题和财务指标定义由代码固定，数值、标准计算和事实溯源不由模型生成。人工可以增删、补项与改方向；未映射的自定义标准判未知。

30项自动测试覆盖主链路、缺失/冲突、接口与模型失败、精确金额、自定义标准、权限、预算、恢复、会话隔离、CSRF、并发和真实服务重启。合同替身与构造数据不作为供应商或真实模型调用证明。48项公开披露核对及官方PDF实际联网下载/哈希证据独立保存。三段60–180秒真实操作视频在各自提交ZIP中，GitHub视频上传曾失败，因此不声称公网视频链接。

## 金融数据与范围

当前产品为贵州茅台600519.SH的2024/2025年报历史研究，结构化值由官方PDF人工提取核对，保留原始金额、报告期、披露日、单位、口径、页码和SHA256。官方原文可从证据卡打开；这是历史样本，不是实时API或全市场覆盖。构造公司只用于故障演练。

金额以十进制字符串存储、整数分值计算同比。主营酒类毛利率不同于合并综合毛利率；归母、扣非归母与主营利润分开。合并现金流包含财务子公司，不能直接作酒类客户回款归因。主营因果缺少费用/成本桥时仍为未知。同公司年报和镜像属于同一披露来源；行业宏观资料不能替代公司财务验证。

扶摇/iFinD不是这条公开数据主链路的必需项。原题写“优先使用”，能力以实际可调用工具为准。本次用户无密钥，未调用这些账户接口，不声称独立公司供应商交叉核验。扶摇适配器仅作为可选扩展保留。

## 保存、权限与故障

公开版的研究、笔记与检查点保存在当前浏览器IndexedDB，是个人设备空间；同源同浏览器使用者共享，不跨设备云同步，不上传笔记或持仓。Web Locks用于同页签空间互斥；不支持时以单页使用为边界。工具开始前保存运行状态，刷新时未完成调用阻断并提示从检查点恢复。

模型、金融读取与原文联网在私有服务中分别审批；真实云端调用不能通过浏览器模式标志跳过审批。停止条件包括调用预算、累计时限、模型实测tokens及最多两次恢复。故障注入仅限构造数据：缺失、冲突、超时、限流、中断一次。真实失败不替换为虚构金额。模型失败保留原规则计划，记录未执行或输出拒绝与已发生用量。

## 可选私有服务

```bash
node server.mjs
# http://127.0.0.1:8000/
# 如确有供应商权限，才本机填写未跟踪.env：
node --env-file=.env server.mjs
```

随机签名HttpOnly会话、CSRF、同源写、操作凭证、限速、并发锁和原子存储已测试。默认回环监听，生产私有部署需HTTPS、可信Origin和持久卷；本次未部署私有云。API密钥、.runtime、.session-key、模型权重与完整PDF均不进入公开仓库或提交包。私有服务的云端模型/扶摇调用尚未实际验收，不影响已验证的免费主路径。
