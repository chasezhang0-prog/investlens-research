# InvestLens · 盈利质量研究台

面向 A 股研究助理：把一条投资假设变成能检查、能中断、能追问的研究任务。

三个入口共享证据内核，各有对应工作流：

| 题目 | 产品主链路 | 独有操作 |
| --- | --- | --- |
| 第1题 AI Native | 盈利质量初筛 → 核对原文 → 人工复核 → 工作稿 | 单一利润规则与多证据规则对照、原文覆盖率、复核率、建稿计时 |
| 第2题 多证据验证 | 自由命题 → 修订子命题/标准 → 正反未知 → 原文 → 比较/追问 | 自定义标准未映射时判未知、原始金额与页码、跨期比较、研究存档 |
| 第3题 投资 X Buddy | 目标 → 可检查计划 → 工具执行 → 追加核验 → 压缩/记忆 → 恢复 | 工具schema、独立外发审批、调用预算、故障演练、持久检查点、调用轨迹 |

## 当前状态

本版本包含真实公司公开年报的**人工核对历史样本**及明确构造的故障演练样本。它不是实时行情服务。2024/2025年报数值由官方PDF逐项核对，原值、披露日、页码及SHA256保留在数据模块和来源审计中。

目前没有用户供应商/模型密钥，**扶摇真实调用、iFinD公司级独立供应商交叉核验、运行时LLM与AI增量效果未验收**。动态规划当前执行可审计规则路径；实际模型接通后仍需人工确认模型计划。开发使用Codex不等于产品运行时调用模型。三题仍有硬门槛时不能声明全部正式完成。

```bash

# 第2题 ?view=verify，第3题 ?view=buddy
node --test test.mjs

```

若本机工具沙盒不允许监听端口，需要允许本地测试服务。源码中的所有测试数据和假模型输出明确属于合同测试，不是供应商/LLM实际验收。

## 公开评审与私有服务

`node build.mjs` 生成 `dist/public`，可托管于 GitHub Pages 等 HTTPS 静态服务。它在浏览器内执行真实确定性工具，数据、研究任务、笔记与检查点保存在当前浏览器的 IndexedDB。**这是个人设备空间，不跨设备云同步**。同源同一浏览器用户共享此空间；清除网站数据会删除档案。不上传用户笔记、持仓或原始记录到公开网站服务器。三入口为 `?view=native`、`?view=verify`、`?view=buddy`。

`server.mjs` 是私有/本机服务：随机签名HttpOnly会话、独立会话资料、CSRF、同源写限制、输入/频率限制、同空间并发锁、文件原子写入、服务重启检查点恢复。`.runtime` 必须持久挂载并定期离线备份；单实例文件存储不能直接扩展成多实例。

公开版本不具备私有金融接口或模型密钥。私有服务中，操作凭证还须通过 `X-InvestLens-Operator` 校验，真实金融读取、原文联网验证和模型资料外发分别审批。操作凭证只保存在当前页内存。默认只监听回环地址。生产私有服务需要HTTPS反向代理、可信Origin配置和持久卷；此部署还未完成。

## 配置真实服务

复制 `.env.example` 为未跟踪的 `.env`，由用户在本机填写，不在聊天、仓库或视频中输入真实密钥。

```bash
node --env-file=.env server.mjs
```

扶摇接口文档：<https://fuyao.aicubes.cn/docs/api-reference/financial-indicators/>；请求仅发往固定官方地址，校验业务code、证券、报告期及重复字段。接口财务指标没有可知日期时，不用于确定的历史判断；真实失败不使用构造数据替代。

可选模型使用标准Chat Completions JSON模式，模型ID可配置；结构、问题ID、工具allowlist及人工审核独立限制。供应商返回token才记用量，未配置单价不显示费用。没有密钥时清楚保留规则后备。实际模型能力需取得密钥后另行验收。

## 架构与证据边界

`core.mjs`：规则澄清、工具注册、目标相关计划、反证触发追加现金流核验、金额BigInt分值计算、证据/记忆/审批/预算/压缩/工作稿。

`data.mjs`：官方披露人工核对样本与明确虚构数据；`adapters.mjs`：原文SHA校验、扶摇契约与可选模型；`app.js/index.html/style.css`：三题交互。

货币金额保存十进制字符串；同比用整数分值计算。酒类主营毛利率不同于合并综合毛利率；归母净利润不同于净利润总额/营业利润；扣非利润也不同于主营利润。毛利率作差为百分点。经营现金流含财务子公司，不直接与归母利润作比得出现金质量评级。

同公司多份年报和SSE镜像仍属同一披露来源。国家统计局行业增加值数据是独立**行业背景**，不能核实公司财务数值、替代公司收入或证明因果。自定义标准没有映射到公式时为未知，不暗用默认阈值。

所有模型文字都是规划建议，不创建已核验事实；手工材料始终待核。人工“已核对/保留异议”进入工作稿，不改写原始数字。

## 故障与恢复

构造模式可演练缺失、冲突、超时、限流或中断一次。失败不前移检查点，最多2次恢复；达到调用/执行时限停止。服务在外部调用前保存“运行中”，重启后对未完成调用提示结果未知，须人工恢复；此类只读调用可能重复计费，不声称exactly-once供应商账单。

上下文压缩保留目标、证据ID及原值路径、未决问题、记忆、检查点；原始库不删除。展示前后实测字符数，不冒充token。
